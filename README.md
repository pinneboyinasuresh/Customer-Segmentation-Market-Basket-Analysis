# Customer Segmentation & Market Basket Analysis

## Project Overview
This project analyzes online retail transaction data to understand customer purchasing behavior, segment customers based on their value, and identify frequently purchased products.

## Objectives
- Clean and prepare online retail transaction data.
- Segment customers using Recency, Frequency, and Monetary (RFM) analysis.
- Understand customer purchasing patterns.
- Identify frequently purchased products and potential cross-selling opportunities.
- Visualize findings using charts.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Project Workflow

### 1. Data Cleaning
Handled missing values and removed duplicate records to prepare the dataset for analysis.

### 2. RFM Analysis
Calculated the following metrics for each customer:
- **Recency:** How recently a customer made a purchase.
- **Frequency:** How often a customer made purchases.
- **Monetary:** How much a customer spent.

### 3. Customer Segmentation
Grouped customers based on their RFM values to identify high-value and frequent customers.

### 4. Market Basket Analysis
Analyzed product purchasing patterns to identify frequently purchased products and potential cross-selling opportunities.

### 5. Data Visualization
Created charts using Matplotlib to present customer segments and key purchasing insights.

## Key Outcomes
- Identified high-value and frequent customer groups.
- Explored customer purchasing behavior.
- Highlighted frequently purchased products and potential cross-selling opportunities.
- Presented findings through visualizations.

## Business Value
This analysis can help businesses understand customer value, plan targeted marketing activities, and identify opportunities for product recommendations and cross-selling.
